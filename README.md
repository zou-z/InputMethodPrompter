# InputMethodPrompter

在输入框边缘显示输入法的当前输入模式（英文键盘、中文模式、英文模式），让输入更便捷。Win32程序在运行时占用内存和CPU都很低。

- 软件运行截图
  
  ![snapshot1](image/snapshot1.png)
  
  ![snapshot2](image/snapshot2.png)
  
  ![snapshot3](image/snapshot3.png)

软件运行后在状态栏会出现一个图标，鼠标右键点击图标可以打开右键菜单，点击退出按钮即可退出软件。
